Animate Project 2

Project Summary

This project creates an interactive door animation in Adobe Animate that opens on mouse-over to reveal a design in the background. It demonstrates skills in timeline control, classic tweening, symbol creation, and ActionScript coding, combining animation and interactivity into a visually engaging project.

Explanation of Tools and Skills

For this project, I used Adobe Animate and ActionScript 3.0 to create an interactive door animation. I imported the door images, converted them into symbols, and created separate layers so each door could be animated independently. Keyframes and classic tweens were used to create smooth sliding animations. Mouse-over events were added to control when the doors opened, and stop actions ensured the animation played correctly. A scenic background was added so it would be revealed when the doors opened. This project demonstrates timeline management, symbol creation, classic tweening, and interactive animation design.
